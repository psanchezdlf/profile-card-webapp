## 🧩 Descripción del proyecto

Aplicación web para crear y compartir tarjetas digitales personalizadas.  
Este proyecto es un **rediseño moderno y funcional** de la versión original propuesta en clase, con un enfoque en **usabilidad, diseño accesible y experiencia de usuario**.

**Awesome Profile Cards** permite a las usuarias crear su propia tarjeta digital en pocos pasos:

1. **Diseña** el estilo visual de la tarjeta.
2. **Rellena** la información personal (nombre, rol, contacto, redes).
3. **Comparte** la tarjeta a través de un enlace generado automáticamente.

La aplicación está desarrollada como parte de un ejercicio de aprendizaje en equipo, donde se ha trabajado de forma ágil, iterando el diseño y la funcionalidad en diferentes _sprints_.

## 🚀 Objetivos del proyecto

- Rediseñar la interfaz con un estilo **más fresco, moderno y coherente visualmente**.
- Mejorar la **usabilidad** y la **experiencia del usuario**.
- Implementar un flujo funcional completo de creación y compartición de tarjetas.
- Practicar metodologías ágiles y trabajo colaborativo.

## 🧰 Tecnologías utilizadas

- **HTML5** – estructura semántica.
- **CSS3 / SASS** – estilos y diseño responsive.
- **JavaScript (ES6)** – lógica de interacción y manejo del DOM.
- **Git & GitHub** – control de versiones y trabajo colaborativo.
- **Fetch API / JSON / LocalStorage** – para gestión de datos y simulación del envío al servidor.
